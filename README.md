# DearScene Beta

しまっていた写真を、景色に。

DearSceneは、フォルダーに眠る写真と動画を選び、整え、静かにめぐらせるWindows向けローカルメディアディスプレイです。

## DearScene v1.21 Beta

- [DearScene v1.21をダウンロード](https://github.com/linohwang001/DearScene-Beta/releases/download/v1.21-beta.1/DearScene-v1.21.exe)
- [意見・不具合をGoogle Formsで送る](https://forms.gle/5TT5WFhG5xzA45oW9)

Windows 10／11向けベータ版です。DearSceneは元の写真・動画を移動・編集しません。
