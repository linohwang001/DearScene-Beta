02 · MULTI LAYOUT

一枚ずつも、
響き合うギャラリーも。

メイソンリーは、縦写真を縦の枠へ、横写真を横の枠へ。3:4、黄金比、16:9を組み合わせ、3・5・7枚の作品がひとつの画面で美しく響き合います。

短冊は、縦へ2〜5分割。作品ごとに並べることも、パノラマ写真や横長動画を一作品のまま、均等な隙間を挟んだ三つの窓として連続表示することもできます。

06 · REDISCOVERY

忘れていた一枚が、
次の発見になる。

ランダムは一巡するまで同じファイルを繰り返しません。順番通り、未鑑賞優先、おすすめも選択可能。気になった一枚はハートボタンまたはLキーでお気に入りへ。見せたくない写真は元ファイルを消さずに隠せます。

08 · ALWAYS READY

次の一枚は、
見えない場所で、もう準備済み。

次に見せる写真や動画を画面の外で先に準備。読み込みに時間がかかる動画や壊れたファイルがあっても、表示できる写真へ切り替え、今見ている作品を急に消しません。

再生が止まりそうな時は自動で別の読み込み方へ。長尺動画や低速なUSB HDDを使う時も、スライドショーが続くことを優先します。

再生中のフォルダーへ新しい写真が追加されたら、保存が終わった後に自動で候補へ。複数の画面で同じHDDを使う環境にも配慮しています。5

  1. 対応形式は、Windowsの標準デコーダー、同梱FFmpeg、RAW内蔵プレビューを組み合わせたものです。ファイルの生成方法や内部形式によっては再生できない場合があります。
  2. アプリ内に固定の登録件数上限はありません。実際に扱える件数、検索時間、先読み速度は、PCの性能、メモリ容量、保存先の速度、同時起動数によって変わります。
  3. メイソンリーと短冊表示は、1枚表示より高い読み出し・デコード負荷がかかります。低速な外付けストレージや長尺動画を使用する場合は、表示時間を長めに設定してください。準備が間に合わない動画は、読込済み写真へ置き換わる場合があります。
  4. スマート構図は、画像内の顔らしさ、ピント、特徴色から端末内で注目位置を推定します。作品の内容や画質によって結果は異なり、人物を識別・特定する機能ではありません。
  5. 停止監視と迂回再生は、すべてのPC、グラフィックドライバー、外部ストレージ構成で無停止動作を保証するものではありません。再生中に追加されたファイルは、書き込みの安定を確認してから候補へ加わります。
  6. DearScene v1.22はWindows 10／11 x64向けベータ版です。本体はネットワーク通信を行わず、元の写真・動画を変更しません。掲載している画面、仕様、対応形式は今後の更新で変更される場合があります。
  7. 配布用EXEは現在コード署名されていません。GitHub Releasesから入手し、同じリリースのMANIFESTに記載したSHA-256と一致することを確認してから実行してください。
